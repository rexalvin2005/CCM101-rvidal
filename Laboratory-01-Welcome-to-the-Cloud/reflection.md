# Reflection

This laboratory activity helped me understand the basics of working with a Linux cloud environment. I learned how to use KillerCoda to access an 
Ubuntu terminal and how to create and configure a new Linux user.
I also learned how to use basic Linux commands to navigate directories, create files, and check system information such as the Linux distribution,
kernel version, CPU, memory, and disk space.
Another important lesson I learned was how to organize laboratory files and use GitHub to store and document my work. Overall, this activity improved
my confidence in using the Linux command line and introduced me to skills that will be useful in Cloud Computing.
