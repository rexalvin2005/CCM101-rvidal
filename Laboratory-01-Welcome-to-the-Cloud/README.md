# Laboratory 01 - Welcome to the Cloud

## Mission Overview

This laboratory activity introduces the basics of cloud computing through a Linux environment using KillerCoda. The mission focuses on exploring Ubuntu, creating a new Linux user, gathering system information, creating a workspace, and documenting the activities using GitHub.

## Objectives

- Explore and use a Linux cloud environment.
- Create and configure a new Linux user.
- Learn basic Linux commands.
- Identify important system information.
- Create and organize files and directories.
- Use GitHub to manage and document laboratory activities.

## Activities Performed

1. Launched an Ubuntu Linux playground using KillerCoda.
2. Created a new Linux user.
3. Configured the user with a home directory, Bash shell, and sudo privileges.
4. Collected information about the Linux distribution, kernel, CPU, memory, and disk space.
5. Created a workspace and Markdown files.
6. Created a GitHub repository for the laboratory activity.
7. Organized the laboratory files and screenshots.

## Linux Commands Used

- `pwd` - Displays the current directory.
- `ls` - Lists files and directories.
- `cd` - Changes the current directory.
- `mkdir` - Creates directories.
- `touch` - Creates files.
- `nano` - Creates and edits text files.
- `cat` - Displays file contents.
- `whoami` - Displays the current user.
- `uname` - Displays system and kernel information.
- `lscpu` - Displays CPU information.
- `free` - Displays memory information.
- `df` - Displays disk space information.
- `git` - Used for version control and GitHub operations.

## Skills Learned

Through this laboratory, I learned how to navigate a Linux environment, manage users, create and organize files, collect system information, and use GitHub to document my laboratory activities.
