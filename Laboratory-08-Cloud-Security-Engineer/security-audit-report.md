# Security Audit Report

## 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving users and applications only the permissions they need to perform their assigned tasks. It is important in cloud environments because it limits unauthorized access and reduces the damage that can happen if an account is compromised.

## 2. Attack Surface

The attack surface is the collection of points where an attacker might try to access or exploit a virtual machine. These can include open network ports, running services, outdated software, and accounts with excessive permissions.

## 3. Default Deny Policy

A Default Deny Policy blocks incoming network traffic unless a specific rule allows it. This is safer than trying to block individual attackers because unknown or unauthorized connections are rejected by default, reducing the number of ways an attacker can reach the server.
