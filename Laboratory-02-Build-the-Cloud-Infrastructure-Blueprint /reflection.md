### Mission Reflection

I think the compute resource is the most important cloud infrastructure component because it provides the computing power needed to run applications,
process data, and support users. Without a compute resource, most cloud services would not be able to operate properly.
Linux supports cloud computing because it is stable, secure, flexible, and widely used for managing cloud servers. It also provides useful command-line
tools that allow cloud engineers to manage files, users, services, and system resources efficiently.
Technical documentation is important before deploying infrastructure because it provides a clear guide for setting up and managing the system. It helps 
prevent mistakes, makes troubleshooting easier, and allows other team members to understand how the infrastructure is organized and configured.
During this laboratory activity, I learned new skills such as using Linux commands, managing files and directories, creating Markdown documentation,
using Git and GitHub, and designing a basic cloud infrastructure diagram. I also learned how different cloud infrastructure components work together
to provide services.
My GitHub portfolio has improved after completing this mission because I was able to organize and document my laboratory activities properly. I added 
important files and documentation that demonstrate my understanding of basic cloud computing concepts. Overall, this mission gave me practical experience
with Linux, GitHub, documentation, and cloud infrastructure, which can help me in future projects and as an aspiring IT professional.
