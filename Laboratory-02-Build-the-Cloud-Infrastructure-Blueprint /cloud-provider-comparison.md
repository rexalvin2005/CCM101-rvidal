# Cloud Provider Comparison

The three major public cloud providers examined in this activity are Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP).

## Infrastructure Service Comparison

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking | Amazon VPC | Azure Virtual Network | Google Cloud VPC |
| Identity and Access Management (IAM) | AWS IAM | Microsoft Entra ID / Azure RBAC | Google Cloud IAM |

AWS provides compute through Amazon EC2, storage through Amazon S3, networking through Amazon VPC, and identity management through AWS IAM. :contentReference[oaicite:0]{index=0}

Azure provides Virtual Machines for compute, Blob Storage for object storage, Virtual Network for networking, and Microsoft Entra ID together with Azure role-based access control for identity and access management. :contentReference[oaicite:1]{index=1}

Google Cloud provides Compute Engine for virtual machines, Cloud Storage for storage, VPC for networking, and Google Cloud IAM for controlling access to resources. :contentReference[oaicite:2]{index=2}

## Guide Questions

### 1. Which cloud provider offers the broadest range of services?

AWS is widely recognized for having a very broad range of cloud services and infrastructure options. It provides many services for computing, storage, networking, databases, security, analytics, and other cloud workloads.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products?

I would recommend Microsoft Azure because it integrates closely with Microsoft's products and services. Organizations already using Microsoft technologies can benefit from Azure's integration with Microsoft identity and management tools.

### 3. Which platform is widely recognized for Artificial Intelligence, Machine Learning, and Kubernetes services?

Google Cloud is widely recognized for its strengths in artificial intelligence, machine learning, data services, and Kubernetes. Google also developed Kubernetes, which contributes to its strong position in container orchestration.

### 4. What similarities did you observe among the three cloud providers?

All three providers offer similar fundamental infrastructure services, including compute, storage, networking, and identity and access management. Although the service names are different, they provide similar functions for building and managing cloud infrastructure.
