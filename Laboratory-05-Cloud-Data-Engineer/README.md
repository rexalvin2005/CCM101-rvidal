# Laboratory 05 - Cloud Data Engineer

## Mission Overview

This laboratory explores cloud storage concepts and demonstrates how to deploy an S3-compatible object storage server using MinIO and Docker.

## Objectives

- Compare block, file, and object storage.
- Understand the purpose of object storage buckets.
- Deploy MinIO in a Docker container.
- Access the MinIO web console.
- Create a bucket and upload a sample file.
- Document the deployment and verification process.

## Tools Used

- KillerCoda Ubuntu Playground
- Linux terminal
- Docker
- MinIO
- MinIO Web Console
- GitHub
- Markdown

## Skills Learned

- Creating folders and Markdown files using Linux commands.
- Comparing cloud storage types.
- Deploying a storage service with Docker.
- Mapping ports to access a containerized application.
- Configuring a container using environment variables.
- Creating buckets and uploading files through a web console.
- Documenting and organizing laboratory work in GitHub.
