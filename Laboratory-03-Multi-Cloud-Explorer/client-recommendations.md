# CloudNova Technologies – Client Recommendations

## Checkpoint 4 – Cloud Platform Recommendation Challenge

## Client A – Startup Company

### Recommended Platform: AWS

AWS is a good choice for the startup because it provides flexible cloud services that can support a small application and scale as the number of users increases. The company can begin with a simple architecture and add more resources as the business grows. AWS also provides many managed services that can reduce the amount of infrastructure the startup needs to maintain. This makes AWS practical for a startup with limited resources and future growth plans.

### Recommended Services

- Amazon EC2
- Amazon S3
- Amazon RDS
- AWS Lambda
- Elastic Load Balancing

---

## Client B – University

### Recommended Platform: Microsoft Azure

Microsoft Azure is the best choice for the university because it already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft technologies and identity services. The university can gradually migrate services while maintaining connections to existing systems. Azure is also suitable for hybrid cloud environments.

### Recommended Services

- Azure Virtual Machines
- Microsoft Entra ID
- Azure Virtual Network
- Azure SQL Database
- Azure Blob Storage

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud

Google Cloud is a strong choice for an AI research company because of its AI, machine learning, data analytics, and high-performance computing capabilities. The company can use Google Cloud services to train and deploy machine learning applications. Google Cloud also provides Kubernetes through Google Kubernetes Engine. This combination makes the platform suitable for advanced research workloads.

### Recommended Services

- Compute Engine
- Vertex AI
- Cloud Storage
- BigQuery
- Google Kubernetes Engine (GKE)

---

## Client D – Global E-Commerce Company

### Recommended Platform: AWS

AWS is a strong choice for a global e-commerce company because it provides scalable and highly available cloud infrastructure. The company can deploy applications across multiple Availability Zones and use automatic scaling to handle changing customer traffic. AWS also provides services for databases, storage, load balancing, monitoring, and content delivery. These capabilities can support a large international e-commerce platform.

### Recommended Services

- Amazon EC2
- Elastic Load Balancing
- EC2 Auto Scaling
- Amazon RDS
- Amazon S3
- Amazon CloudFront

# Checkpoint 6 – Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | Flexible services and strong scalability |
| Enterprise Organization | AWS | Broad enterprise services and mature infrastructure |
| Microsoft Environment | Azure | Strong Microsoft integration |
| AI / Machine Learning | Google Cloud | Strong AI and machine learning ecosystem |
| Kubernetes Deployment | Google Cloud | Google Kubernetes Engine provides managed Kubernetes |
| Global Web Application | AWS | Strong global infrastructure and scalability |

## Consultant's Summary

There is no single cloud platform that is perfect for every organization.

A cloud solutions consultant should consider the client's budget, existing technology, application requirements, security needs, geographic requirements, scalability, and technical skills before selecting a cloud provider.
