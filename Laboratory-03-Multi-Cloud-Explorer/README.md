## Introduction

This laboratory explores three major cloud computing platforms: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP).

The purpose of this activity is to compare the major cloud providers, identify their core services, recommend suitable platforms for different businesses, and investigate how a Linux server can be migrated to the cloud.
