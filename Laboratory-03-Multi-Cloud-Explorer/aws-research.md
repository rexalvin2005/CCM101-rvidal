# Amazon Web Services (AWS) Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform developed by Amazon. It provides services for computing, storage, networking, databases, security, analytics, artificial intelligence, containers, and application development.

AWS allows organizations to use cloud resources without purchasing and maintaining all of their own physical servers.

AWS is commonly used by startups, enterprises, government organizations, developers, and large online businesses.

## Global Infrastructure

AWS operates its infrastructure using Regions and Availability Zones.

A Region represents a separate geographic area, while Availability Zones are isolated locations inside a Region.

AWS currently operates 39 geographic Regions and 124 Availability Zones. AWS also continues to expand its infrastructure by announcing additional Regions and Availability Zones.

This global infrastructure allows organizations to deploy applications closer to their customers and improve availability.

## Cloud Management Console

The AWS Management Console is a web-based interface used to create, configure, monitor, and manage AWS resources.

Through the console, users can access services such as EC2, S3, RDS, VPC, IAM, CloudWatch, and many other AWS services.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual servers in the AWS cloud.

Organizations can select the operating system, CPU, memory, storage, and other configurations needed for their applications.

### 2. Amazon S3

Amazon Simple Storage Service (S3) is an object storage service.

It can store images, videos, documents, backups, application files, and other types of data.

### 3. Amazon VPC

Amazon Virtual Private Cloud (VPC) provides a private networking environment for AWS resources.

It allows organizations to configure subnets, routing, security groups, and network connections.

### 4. AWS IAM

AWS Identity and Access Management (IAM) controls access to AWS resources.

Administrators can create users, groups, roles, and permissions to help protect cloud resources.

## Three Advantages

### 1. Wide Range of Services

AWS provides a large number of services covering computing, storage, databases, networking, security, analytics, AI, and more.

### 2. Global Infrastructure

AWS has infrastructure in many geographic locations around the world.

### 3. Scalability

AWS resources can be increased or decreased depending on application requirements.

## Typical Enterprise Use Cases

AWS can be used for:

- Web application hosting
- Mobile application backends
- E-commerce systems
- Data backup
- Disaster recovery
- Database hosting
- Artificial intelligence
- Machine learning
- Container applications
- Enterprise applications
