# Cloud Platform Comparison

| Category | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Launch Year | 2006 | 2010 | 2008 |
| Compute Service | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage Service | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking Service | Amazon VPC | Azure Virtual Network | Google Cloud VPC |
| Identity Service | AWS IAM | Microsoft Entra ID | Google Cloud IAM |
| Primary Strength | Broad cloud services | Microsoft integration | AI, data, and Kubernetes |
| Ideal Organizations | Startups and enterprises | Microsoft-based organizations | AI and cloud-native organizations |

## Questions

### 1. Which cloud provider offers the broadest range of services?

AWS offers one of the broadest ranges of cloud services. It provides services for computing, storage, networking, databases, security, analytics, artificial intelligence, containers, and many other workloads.

### 2. Which provider best integrates with Microsoft technologies?

Microsoft Azure provides the strongest integration with Microsoft technologies. It works well with Windows Server, Microsoft 365, Microsoft Entra ID, and existing Microsoft enterprise environments.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?

Google Cloud is a strong choice for Artificial Intelligence, Machine Learning, and Kubernetes. Google created Kubernetes and provides Google Kubernetes Engine (GKE), while also offering many AI and data services.

### 4. Which cloud platform would you personally choose and why?

I would personally choose AWS because it provides a very broad range of services and gives me opportunities to learn different areas of cloud computing. It is also flexible enough to support startups, enterprises, web applications, databases, storage, networking, and many other workloads.

# Checkpoint 5 – Matching Cloud Services

| Service Category | AWS | Azure | GCP |
|---|---|---|---|
| Virtual Machine | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Object Storage | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Identity Management | AWS IAM | Microsoft Entra ID | Cloud IAM |
| SQL Database | Amazon RDS | Azure SQL Database | Cloud SQL |
| Kubernetes | Amazon EKS | Azure Kubernetes Service (AKS) | Google Kubernetes Engine (GKE) |

## Explanation

The three cloud providers offer similar fundamental cloud services.

For example, EC2, Azure Virtual Machines, and Compute Engine all provide virtual machines. Similarly, S3, Azure Blob Storage, and Cloud Storage provide object storage.

The main difference is the ecosystem, features, pricing, management tools, and integrations offered by each provider.
