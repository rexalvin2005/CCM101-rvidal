# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud Platform (GCP), commonly called Google Cloud, is Google's cloud computing platform.

It provides services for computing, storage, databases, networking, artificial intelligence, machine learning, analytics, containers, and application development.

Google Cloud is especially known for its strengths in artificial intelligence, machine learning, data analytics, and Kubernetes.

## Global Infrastructure

Google Cloud uses Regions and Zones.

A Region represents a geographic location while Zones provide separate infrastructure locations within a Region.

Google Cloud currently provides 43 global regions and 130 zones.

This infrastructure helps organizations deploy applications globally while improving performance and availability.

## Cloud Management Console

Google Cloud Console is the web-based management interface for Google Cloud.

Users can create, configure, monitor, and manage cloud resources through the console.

Google Cloud also provides command-line tools and APIs for cloud management.

## Four Core Services

### 1. Compute Engine

Compute Engine provides virtual machines running on Google's infrastructure.

Organizations can select different machine types, operating systems, storage, and networking configurations.

### 2. Cloud Storage

Cloud Storage is Google's object storage service.

It can store files, images, videos, backups, application data, and other unstructured data.

### 3. Google Cloud VPC

Google Cloud Virtual Private Cloud provides networking for cloud resources.

It supports networks, subnets, routing, firewall rules, and connections between cloud and on-premises environments.

### 4. Google Cloud IAM

Google Cloud Identity and Access Management controls access to Google Cloud resources.

Administrators can assign roles and permissions to users and services.

## Three Advantages

### 1. Artificial Intelligence and Machine Learning

Google Cloud provides a strong ecosystem for AI and machine learning applications.

### 2. Kubernetes

Google developed Kubernetes and provides Google Kubernetes Engine (GKE) as a managed Kubernetes service.

### 3. Data Analytics

Google Cloud provides powerful data analytics services that can process large amounts of information.

## Typical Enterprise Use Cases

Google Cloud can be used for:

- Artificial intelligence
- Machine learning
- Big data analytics
- Kubernetes applications
- Web applications
- Mobile applications
- Data warehouses
- Global applications
- High-performance computing
