# Microsoft Azure Research

## Brief Overview

Microsoft Azure is Microsoft's cloud computing platform.

Azure provides services for computing, storage, networking, databases, security, artificial intelligence, analytics, containers, and application development.

Azure is particularly useful for organizations that already use Microsoft technologies such as Windows Server, Microsoft 365, and Microsoft identity services.

## Global Infrastructure

Azure provides a worldwide cloud infrastructure made up of regions and datacenters.

Microsoft currently lists more than 80 Azure regions and more than 500 datacenters worldwide.

Azure's global infrastructure allows organizations to deploy applications closer to users and meet requirements involving performance, availability, and data residency.

## Cloud Management Console

The Azure Portal is Microsoft's web-based cloud management interface.

Users can create, configure, monitor, and manage Azure resources through the portal.

Azure also provides command-line and PowerShell tools for cloud administration.

## Four Core Services

### 1. Azure Virtual Machines

Azure Virtual Machines provide virtual computers running Windows or Linux.

Organizations can select different CPU, memory, storage, and networking configurations.

### 2. Azure Blob Storage

Azure Blob Storage is an object storage service designed for large amounts of unstructured data.

It can store images, videos, documents, backups, logs, and other files.

### 3. Azure Virtual Network

Azure Virtual Network provides private networking for Azure resources.

It supports subnets, routing, network security, and connections to on-premises environments.

### 4. Microsoft Entra ID

Microsoft Entra ID is Microsoft's cloud identity and access management service.

It helps organizations manage users, authentication, applications, and access permissions.

## Three Advantages

### 1. Microsoft Integration

Azure works closely with Microsoft products such as Windows Server, Microsoft 365, and Microsoft identity technologies.

### 2. Global Infrastructure

Azure has a large worldwide infrastructure with many regions and datacenters.

### 3. Hybrid Cloud

Azure provides tools that allow organizations to connect on-premises infrastructure with cloud resources.

## Typical Enterprise Use Cases

Azure can be used for:

- Windows Server migration
- Enterprise applications
- Microsoft 365 integration
- Hybrid cloud
- Database hosting
- Web applications
- AI and machine learning
- Virtual desktop infrastructure
- Backup and disaster recovery
