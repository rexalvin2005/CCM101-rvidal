# Automation Research

## 1. Bash Script

A Bash script is a text file containing Linux commands that run in sequence to automate tasks. The line `#!/bin/bash`, called the shebang, tells the operating system to use the Bash interpreter to execute the script.

## 2. Variables

Variables store values, such as directory paths, filenames, or timestamps, so they can be reused throughout a script. For example, `$BACKUP_DIR` allows a programmer to change the backup location in one place instead of editing several commands.

## 3. Cron Job

A cron job is a scheduled task in Linux that runs a command or script automatically at a specified time or interval. It is useful in cloud operations because tasks such as backups, log cleanup, and routine maintenance can run regularly without requiring someone to start them manually.
